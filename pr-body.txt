# HOM-1430: Replace `any` casts with proper types in Agent CLI commands

## Summary

Replace 10 `any` casts across 9 CLI command files with properly typed alternatives.

## Changes

| File | Change |
|------|--------|
| `args.ts` | Use `SchemaAST.AST` and `Schema.Schema<unknown>` for AST types |
| `cli.ts` | Use `ParseResult.ParseError` for error mapping |
| `events/list.ts` | Cast to `string[]` for eventType array |
| `graphs/graph-edit.ts` | Use `GraphEditBody` interface instead of `Record<string, unknown>` |
| `keywords/keyword-edit.ts` | Use `KeywordEditBody` interface instead of `Record<string, unknown>` |
| `run-command.ts` | Use `unknown` for schema decoded type parameter |
| `settings/setting-edit.ts` | Use `SettingEditBody` interface, remove `as any` |
| `socialposts/socialpost-edit.ts` | Use `SocialPostEditBody` interface, remove `as any` |
| `areas/create.ts` | Import `Geometry` type directly, use proper decoded type |
| `areas/edit.ts` | Import `Geometry` type directly, use proper decoded type |

## Verification

```
pnpm --filter agent lint  -> 0 errors, 8 warnings (pre-existing, outside scope)
```

## Risk

Low. Only type changes, no behavioral changes. All affected files are CLI command handlers that don't modify business logic.
